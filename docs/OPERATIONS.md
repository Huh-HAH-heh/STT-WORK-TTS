# Эксплуатация STT Work TTS

Практическая инструкция для Windows x64. Основной способ запуска приложения не меняется: используется **Start.cmd** в корне проекта или распакованного portable-архива.

## 1. Запуск из исходного кода

### Требования

- Windows x64.
- .NET 10 SDK.
- Интернет при первой подготовке моделей и зависимостей.
- Python 3.12 x64 нужен для движков Silero и xVibe. Для профиля laptop с Piper Python не требуется.

### Первый запуск

1. Клонируй ветку `main` или актуальную опубликованную версию репозитория.
2. Открой папку проекта.
3. Запусти:

```cmd
Start.cmd
```

Сценарий проверит локальные компоненты, при необходимости подготовит модель Vosk и выбранный TTS-движок, затем запустит приложение. При первом запуске загрузка моделей может занять время.

Обычный профиль использует настройки из `src/STT.WorkTTS/appsettings.json`. В текущей конфигурации основным TTS является Silero.

## 2. Лёгкий профиль

Для компьютера с ограниченными ресурсами можно запустить:

```cmd
Start.cmd --profile laptop
```

Профиль laptop использует Piper и встроенный C# каталог команд. Он не запускает RuBERT/ONNX и Qwen generation, поэтому для этого профиля не нужны Python, llama-server или GPU.

В исходной копии при первом запуске всё ещё может потребоваться загрузить недостающие ресурсы. В готовом переносимом архиве Vosk и Piper уже включены.

## 3. Переносимая сборка

Сборка архива выполняется на компьютере разработчика с Windows x64, .NET 10 SDK и доступом к загрузке необходимых ресурсов.

Запуск сборки:

```cmd
RUN.cmd
```

Или напрямую:

```powershell
.\build_portable.ps1 -Clean
```

В корне появятся:

- `STT-WORK-TTS-Windows-x64.zip` — приложение и ресурсы для переноса;
- `STT-WORK-TTS-Windows-x64.zip.sha256` — контрольная сумма архива.

На целевом компьютере распакуй ZIP и запусти **Start.cmd**. Для laptop-сборки не нужны Python, .NET SDK, Ollama, llama-server или GPU. Сам архив не следует распаковывать поверх исходного репозитория.

## 4. Проверка компонентов

Проверить микрофон и распознавание без синтеза:

```cmd
Start.cmd --profile laptop --stt-demo
```

Проверить маршрутизацию команд текстом, без микрофона:

```cmd
Start.cmd --profile laptop --intent-demo
```

Переопределить TTS-движок на один запуск:

```cmd
Start.cmd --tts piper
```

Поддерживаемые варианты TTS: `silero`, `xvibe`, `piper`, `sapi`. Для Silero и xVibe требуется подготовленное Python 3.12 окружение. SAPI использует голоса, установленные в Windows.

Во время озвучивания нажми `Esc`, чтобы остановить текущую фразу. Для завершения приложения используй `Ctrl+C` в окне запуска.

## 5. Повседневное использование

Примеры команд:

```text
открой блокнот
поставь таймер на 5 минут
установи громкость на 40 процентов
покажи сведения о системе
покажи сетевые подключения
покажи активные процессы
включи ночную гамму
верни обычную гамму
заблокируй компьютер
```

Доступные действия зависят от текущего каталога команд. При свободной формулировке маршрутизатор может не распознать намерение — перефразируй запрос или используй более прямую команду.

Опасные действия, включая блокировку компьютера, закрытие процессов и буквальные CMD-запросы, требуют подтверждения. Для CMD действует ограниченный список разрешённых диагностических команд; произвольные PowerShell-скрипты и цепочки команд не исполняются.

## 6. Настройки и данные

Настройки исходной версии:

- основной профиль: `src/STT.WorkTTS/appsettings.json`;
- лёгкий профиль: `src/STT.WorkTTS/appsettings.laptop.json`.

В переносимом архиве файлы настроек находятся рядом с приложением.

По умолчанию отключено сохранение исходных записей, заметок и синтезированной речи. Не включай эти параметры на общем компьютере без необходимости. Если сохранение включено вручную, рабочие файлы появляются в каталогах `data/recordings`, `data/notes.txt` и `data/speech`.

Примеры фраз и синонимов находятся в `tools/intent/dataset/commands.jsonl`. Новые варианты команд можно добавлять туда; переобучение ONNX-модели требуется только при необходимости обновить сам классификатор.

## 7. Типовые проблемы

| Симптом | Что проверить |
|---|---|
| Не найден .NET SDK | Установить .NET 10 SDK и повторить `Start.cmd` |
| Не найдено устройство записи | Проверить разрешение Windows на доступ к микрофону и выбранное устройство ввода |
| Silero/xVibe не запускается | Проверить Python 3.12 x64; при необходимости повторить подготовку TTS через сценарий запуска |
| Первый запуск долго готовит компоненты | Проверить подключение к интернету и дождаться завершения загрузки моделей |
| Команда не распознана | Повторить её более прямой формулировкой; проверить наличие примера в каталоге команд |
| Нет звука | Проверить устройство вывода Windows и настройки `Tts.PlayAudio` |

## 8. Приватность

Распознавание и обработка выполняются локально. По умолчанию исходная запись, заметки и синтезированная речь не сохраняются на диск. Для отдельных optional-моделей могут скачиваться веса в локальные каталоги; они не хранятся в Git.

Сведения о сторонних библиотеках, моделях и условиях распространения смотри в [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md).
