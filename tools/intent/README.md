# RuBERT-tiny2 command router

Быстрый маршрутизатор использует RuBERT-tiny2 ONNX INT8 на CPU. На runtime не нужны Python, llama.cpp, Ollama или сетевой HTTP endpoint.

## Как обрабатывается фраза

1. RuBERT предлагает класс намерения.
2. При низкой уверенности включается лёгкий semantic-example fallback: нормализует формы слов, сводит распространённые синонимы к смысловым признакам и сравнивает фразу с примерами из `commands.jsonl`.
3. План проходит `IntentPlanValidator`; слот/аргумент извлекается C#, а Windows-действие выполняет отдельный executor.
4. Если совпадение неоднозначно, помощник задаёт уточняющий вопрос. Он не должен угадывать системное действие.

Набор примеров копируется в папку `intent` рядом с приложением, поэтому fallback работает и в portable-сборке.

## Обучение

Запускать на основном ПК, не на ноутбуке 4 ГБ:

```powershell
.\tools\intent\Train-RuBertIntent.ps1
```

Исходный энкодер: `cointegrated/rubert-tiny2`. Скрипт создаёт классификационную голову по классам из JSONL, сохраняет словарь/метки, экспортирует ONNX и применяет динамическую INT8-квантизацию.

Данные находятся в `tools/intent/dataset/commands.jsonl`. Формат строки:

```json
{"text":"Открой блокнот","label":"app.open"}
```

Добавляй естественные варианты команд и реальные ошибки Vosk. Эти примеры одновременно используются обучением и semantic-example fallback. После изменения набора запускай обучение повторно, чтобы обновить ONNX-модель.

После обучения должны существовать: `assets/intent/rubert-tiny2-intent-int8.onnx`, `vocab.txt` и `labels.json`.

Модель выбирает намерение, но не формирует команды оболочки и не имеет прямого доступа к Windows API.
