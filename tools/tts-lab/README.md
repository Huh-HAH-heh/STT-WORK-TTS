# TTS Lab

Отдельная экспериментальная площадка для сравнения русских локальных голосов. Основное приложение остаётся на C#; Python используется только в изолированных адаптерах тех TTS-движков, у которых официальный inference-интерфейс Python.

## Что сравнивается

| Движок | Голоса | Режим |
|---|---|---|
| Piper | Denis, Dmitri, Irina, Ruslan | CPU, ONNX |
| xVibePocketTTS | male_deep, female_silky, male_authoritative | CPU, клонирование по WAV |
| Silero v5.6 | Aidar, Baya, Kseniya, Xenia, Eugene | CPU |
| Vosk-TTS 0.9 | speaker 0–4 | CPU |
| XTTS-v2 | Ana Florence, Andrew Chipper | CPU, мультиязычный синтез (встроенные speaker embeddings, не русские исходные голоса) |

Итого — до 19 вариантов. XTTS включается только после отдельного подтверждения условий лицензии.

## Требования

- Windows 10/11 x64.
- Python 3.12 x64 с py launcher.
- Git для загрузки xVibePocketTTS.
- PowerShell 5.1 или новее.
- Несколько гигабайт свободного места. PyTorch, XTTS и модель Vosk-TTS скачиваются отдельно.
- Для первого скачивания моделей нужен интернет. После скачивания синтез локальный.

AMD RX 7600 не используется этими скриптами как CUDA-ускоритель: сравнение по умолчанию идёт на CPU, чтобы все кандидаты запускались одинаково. xVibe и XTTS можно исследовать отдельно с другими backend, но здесь приоритет — воспроизводимый CPU-тест.

## Установка

Из корня репозитория:

~~~powershell
powershell -ExecutionPolicy Bypass -File .\tools\tts-lab\Install-TtsLab.ps1
~~~

Установить только один движок:

~~~powershell
powershell -ExecutionPolicy Bypass -File .\tools\tts-lab\Install-TtsLab.ps1 -Engine silero
~~~

Допустимые значения Engine: all, piper, xvibe, silero, vosk, xtts.

Каждый Python-движок получает отдельное виртуальное окружение в tools/tts-lab. Это намеренно: Torch, Transformers и зависимости разных TTS-проектов не должны конфликтовать с основным .NET-приложением или друг с другом.

## Прослушивание

Запусти:

~~~cmd
tools\tts-lab\TtsLab.cmd
~~~

Лаборатория сгенерирует один и тот же текст для всех доступных голосов, затем по очереди воспроизведёт WAV. После каждого голоса можно поставить оценку от 1 до 5 и оставить комментарий.

Можно передать собственную фразу:

~~~powershell
powershell -ExecutionPolicy Bypass -File .\tools\tts-lab\Run-TtsLab.ps1 -Text "Проверка голоса. Ну что, удивишь меня?"
~~~

Для дополнительного теста клонирования укажи чистый WAV-образец одного говорящего (для xVibe рекомендуется 1–30 секунд, без музыки и фонового шума):

~~~powershell
.\tools\tts-lab\Run-TtsLab.ps1 -ReferenceWav "C:\VoiceSamples\my_voice.wav"
~~~

Тогда xVibe и XTTS дополнительно создадут варианты с тембром из этого WAV. Для XTTS потребуется отдельно принять условия лицензии.

Только генерация, без автоматического воспроизведения:

~~~powershell
.\tools\tts-lab\Run-TtsLab.ps1 -NoPlayback
~~~

Результаты каждой сессии хранятся в tools/tts-lab/output/<дата-время>/. Оценки добавляются в tools/tts-lab/ratings.csv. Эти папки и локальные виртуальные окружения игнорируются Git.

## Условия и ограничения моделей

- xVibePocketTTS: код репозитория MIT; базовые веса Pocket TTS и сторонние голосовые ресурсы имеют собственные условия. Смотри upstream NOTICE.
- Silero: код, модели и конкретные семейства голосов могут иметь разные условия. Для локальной оценки используем оригинальный репозиторий; перед распространением модели проверь её актуальные условия.
- Vosk-TTS: код опубликован под Apache 2.0; веса модели — отдельный ресурс, проверь их карточку.
- XTTS-v2: Coqui Public Model License разрешает некоммерческое использование модели и её аудиовыхода. Для коммерческого проекта этот кандидат нельзя считать свободным без получения иных прав.
- Piper: runtime распространяется под GPL-3.0-or-later; отдельные ONNX-голоса имеют собственные model cards. В лабораторию модели не коммитятся.

Дополнительные Piper-модели хранятся в tools/tts-lab/models/piper, остальные — в tools/tts-lab/models и локальных кэшах. Они не включаются в Git и не копируются в основной portable ZIP. Piper runtime использует общий assets/piper, который уже нужен базовому приложению.

## Что фиксировать при сравнении

1. Естественность и «характер» голоса.
2. Интонация вопроса, удивления и шутливой фразы.
3. Ударения, окончания и произношение чисел.
4. Скорость генерации и задержка до начала речи.
5. Размер модели, потребление RAM и возможность работы на CPU.

Оценка в CSV субъективна. Для более строгого теста используй одинаковый текст, одну громкость и несколько повторов, а не только одну удачную фразу.
