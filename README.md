# STT Work TTS — локальный голосовой интерфейс Windows

STT Work TTS — Windows-приложение для голосового управления компьютером. Оно объединяет офлайн-распознавание речи, маршрутизацию пользовательских намерений, безопасное выполнение системных действий и синтез голосового ответа.

## Возможности

- Распознавание русской речи локальной моделью Vosk.
- Обработка команд через быстрый каталог фраз и необязательный классификатор RuBERT-tiny2 ONNX.
- Формирование и проверка типизированного плана действия до его исполнения.
- Управление функциями Windows через Win32 API, Core Audio и отдельные адаптеры.
- Голосовой ответ через Silero, Piper и дополнительные TTS-движки.
- Лёгкий профиль для маломощных компьютеров без Python и ONNX-модели в runtime.

## Архитектура

```text
Микрофон
   ↓
Vosk STT
   ↓
Каталог фраз / необязательный RuBERT
   ↓
Intent Router → проверка IntentPlan
   ↓
Windows API / Core Audio / ограниченный CMD-адаптер
   ↓
TTS → динамики
```

Модель не получает прямого доступа к Windows API и не генерирует произвольные shell-команды. Опасные действия требуют подтверждения; для буквальных CMD-запросов используется ограниченный список разрешённых команд.

## Технологии

C# · .NET 10 · NAudio · Vosk · Win32 API · Core Audio · ONNX Runtime · RuBERT-tiny2 · Silero TTS · Piper

## Текущий статус

Рабочий функциональный прототип. Голосовой цикл и набор системных действий реализованы, но распознавание намерений при нестандартных и неоднозначных формулировках ещё требует улучшения. Пользовательский интерфейс остаётся минималистичным; основной сценарий взаимодействия — голосовой ввод и вывод в окне приложения.

## Запуск и эксплуатация

Основной способ запуска сохранён: **`Start.cmd`** в корне проекта. Сборка переносимого архива выполняется отдельно через `RUN.cmd`.

Подробные инструкции по запуску, профилям, проверке распознавания, настройкам и устранению проблем находятся в [docs/OPERATIONS.md](docs/OPERATIONS.md).
