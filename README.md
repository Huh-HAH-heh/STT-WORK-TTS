# STT Work TTS

Компактный автономный голосовой помощник для Windows x64 и слабых CPU-ПК.

Конвейер:

    Микрофон → Vosk Small RU → локальные команды → Piper TTS → динамики

Никаких облачных API, Ollama, GPU или большой языковой модели. Аудио и распознанная речь остаются на компьютере.

## Почему стек лёгкий

- Vosk Small RU — компактное офлайн-распознавание русской речи на CPU. Архив исходной модели около 45 МБ.
- Piper TTS — нейросетевой синтез через ONNX Runtime, без PyTorch. Каждая русская medium-модель около 63 МБ.
- PCM16 — аудио сразу хранится в компактном байтовом буфере, без NumPy и float32-массивов.
- Один worker — распознавание, обработка и синтез идут последовательно, тяжёлые модели не запускаются параллельно.
- Загрузка по требованию — активируется только выбранная модель голоса.
- Обработчик команд обычный Python — нет постоянного потребителя памяти в виде LLM.

## Полностью автономный запуск

Для конечного пользователя предусмотрен переносимый ZIP.

1. Скачай STT-WORK-TTS-Windows-x64 из GitHub Actions → Artifacts.
2. Распакуй ZIP в любую папку.
3. Запусти Start.cmd.

На целевом ПК не нужны Python, pip, интернет, Ollama, GPU или предварительная установка моделей. Модели и runtime уже находятся рядом с EXE. При запуске ничего не скачивается.

### Получение готового ZIP через GitHub Actions

Workflow Build offline Windows archive собирает приложение после push в feature/lightweight-offline и при ручном запуске из вкладки Actions. После успешного запуска ZIP будет доступен как artifact.

### Самостоятельная сборка архива

Сборка выполняется один раз на компьютере разработчика. Нужны Windows x64, Python 3.12 x64 и интернет на этапе сборки.

    git clone -b feature/lightweight-offline --single-branch https://github.com/Huh-HAH-heh/STT-WORK-TTS.git
    cd STT-WORK-TTS
    .\RUN.cmd

RUN.cmd автоматически запускает build_portable.ps1, если готовая сборка ещё не существует. Архив создаётся в корне проекта:

    STT-WORK-TTS-Windows-x64.zip

Сборщик загружает Vosk Small RU и Piper-голоса, устанавливает локальные зависимости, собирает приложение через PyInstaller и упаковывает EXE вместе с моделями. После этого ZIP можно перенести на другой Windows x64 ПК и использовать без сети.

Альтернативно можно вызвать сборщик напрямую:

    powershell -ExecutionPolicy Bypass -File .\build_portable.ps1

Повторная чистая сборка:

    powershell -ExecutionPolicy Bypass -File .\build_portable.ps1 -Clean

## Голоса

В config.toml:

    [tts]
    voice = "female"

- female — русская модель Piper Irina.
- male — русская модель Piper Denis.

Обе модели включаются в автономный архив. Переключение не требует скачиваний или перезапуска системы.

Piper не генерирует новый тембр из текстового промпта: используются готовые модели дикторов. Это сознательный компромисс в пользу низкой нагрузки, автономности и быстрого CPU-инференса.

**Лицензионное ограничение женской модели:** официальная карточка Irina указывает для обучающего датасета RHVoice лицензию Unknown. Поэтому модель оставлена как локальная экспериментальная опция. Перед публичным распространением ZIP с Irina или коммерческим использованием необходимо отдельно получить подтверждение прав. Runtime Piper распространяется под GPL-3.0-or-later; соблюдай её условия и включай лицензии зависимостей в распространяемый архив. Карточка мужского Denis указывает CC0 для его датасета, но это не отменяет проверки прав на базовую модель.

## Что умеет обработчик без LLM

Скажи «помощь», чтобы получить список доступных команд.

- «Который час?» — текущее системное время.
- «Какая сегодня дата?» — системная дата.
- «Посчитай 17 плюс 25» — простая арифметика.
- «Запомни купить молоко» — заметка в RAM.
- «Покажи заметки» — чтение заметок текущего запуска.
- «Очисти заметки» — очистка списка.

Это не свободный диалог с ИИ. Неизвестная команда будет распознана и озвучена, а не выдуманно исполнена. Система обработчиков намеренно отделена от STT и TTS, чтобы позже расширять функциональность без смены аудиодвижков.

## Настройки RAM и файлов

По умолчанию все флаги сохранения выключены:

    [audio]
    save_recordings = false

    [work]
    save_notes = false

    [tts]
    save_speech = false

Исходное аудио, заметки и синтезированная речь остаются в памяти и теряются после завершения программы. Нужное сохранение можно включить отдельно в config.toml.

Максимальная длительность одной записи — 90 секунд. Это ограничивает размер аудиобуфера.

## Структура проекта

    src/stt_work_tts/
      capture/        # микрофон и PCM16 RAM
      stt/            # Vosk
      processing/     # очередь и офлайн-команды
      tts/            # Piper
      audio_output.py # воспроизведение и WAV
      config.py
      domain.py
      main.py

    assets/
      models/         # скачивается при создании ZIP
      voices/         # скачивается при создании ZIP

    build_portable.ps1
    Start.cmd
    RUN.cmd
    config.toml

## Ограничения первой версии

- Запись пока push-to-talk: Enter начинает, Enter завершает.
- Vosk Small уступает большим моделям в точности при шуме, нескольких говорящих и сложной речи.
- Обработчик команд детерминированный: свободный диалог требует более мощной локальной модели и не входит в минимальную сборку.
- Голоса Piper — заранее обученные тембры, а не произвольное клонирование или voice design.
- Переносимый архив сейчас собирается под Windows x64. Другие ОС потребуют отдельных сборочных workflow.
- Реальный расход RAM и скорость зависят от конкретного CPU, количества памяти и драйвера звукового устройства; проект пока не прошёл тестирование на целевых слабых ПК.
