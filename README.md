# STT Work TTS — C# edition

Локальный голосовой помощник для Windows x64. Основной конвейер: **микрофон → Vosk STT → C# маршрутизатор команд → Windows API → TTS**. Для повышения устойчивости к незнакомым формулировкам основной профиль может дополнительно использовать RuBERT-tiny2 ONNX.

## Архитектура

- **STT:** Vosk Small RU, полностью локально.
- **Сопоставление команд:** C# использует каталог фраз и синонимов. В ноутбучном профиле этого достаточно для автономной маршрутизации без обучения; на основном ПК можно включить RuBERT-tiny2 ONNX INT8 как дополнительный классификатор для более свободных формулировок.
- **Извлечение параметров:** детерминированный C# код. Модель выбирает намерение, а C# извлекает число, приложение, URL или процесс и формирует типизированный IntentPlan.
- **Проверка:** IntentPlanValidator проверяет допустимые действия, аргументы и соответствие команде пользователя.
- **Исполнение:** каталог типизированных действий Windows API / Win32 / Core Audio и отдельный безопасный CMD-адаптер.
- **TTS:** Silero v5.6 по умолчанию; xVibe как дополнительный движок; Piper и SAPI доступны как лёгкие варианты.
- **Qwen3-4B:** необязательный генератор свободных ответов/текстов. Он не используется для сопоставления команд и отключён по умолчанию; включается отдельно только при необходимости.

Модель не генерирует PowerShell, CMD или произвольный код. Опасные действия (блокировка ПК, закрытие процесса, буквальный CMD-запрос) требуют подтверждения. Закрытие процесса начинается со штатного CloseMainWindow; принудительное завершение не выполняется автоматически. CMD разрешает только отдельные диагностические команды из whitelist.

## Профили запуска

### Основной компьютер

На основном ПК запускай:

```cmd
Start.cmd
```

Этот профиль использует каталог быстрых совпадений, RuBERT-tiny2 (когда модель подготовлена и включена) для команд и Silero для речи. Qwen3-4B по умолчанию отключена. Для свободных ответов её можно отдельно включить через `Generation.Enabled` в `src/STT.WorkTTS/appsettings.json`.

### Слабый ноутбук (4 ГБ RAM)

```cmd
Start.cmd --profile laptop
```

Профиль ноутбука:
- Vosk Small RU для распознавания речи;
- встроенный C# каталог из примеров и семантическое сопоставление фраз — без RuBERT, ONNX и обучения;
- Piper для синтеза речи;
- Qwen3-4B выключена, llama-server не запускается.

Это не урезанный удалённый клиент. Ноутбук использует тот же ActionCatalog, CommandScriptParser, IntentPlanValidator, извлечение параметров и WindowsActionExecutor. Сохраняются системные, сетевые, Docker, мультимедийные, аудио, гамма, процессные, таймерные и CMD-действия, включая подтверждения опасных операций. Отличается только способ классификации фраз: без RuBERT незнакомые формулировки могут определяться менее точно, но сами обработчики команд не удаляются.

## Необязательное обучение RuBERT на основном ПК

Для ноутбучной сборки обучение не требуется. Команды маршрутизируются встроенным C# сопоставителем по каталогу `tools/intent/dataset/commands.jsonl`.

RuBERT-tiny2 можно отдельно дообучить на основном ПК, чтобы повысить точность при свободных и незнакомых формулировках в основном профиле. Это необязательное улучшение; для laptop-профиля `Intent.UseOnnx=false`.

1. Установи Python 3.12 x64 на основном компьютере.
2. Из корня репозитория выполни:

```powershell
.\tools\intent\Train-RuBertIntent.ps1
```

3. Скрипт создаст изолированное окружение, скачает базовую RuBERT-tiny2, обучит классификационную голову, экспортирует ONNX и динамически квантует MatMul/Gemm в INT8.
4. Готовые файлы появятся в `assets/intent`:
   - `rubert-tiny2-intent-int8.onnx`
   - `vocab.txt`
   - `labels.json`
   - `training-info.json`

Размер ONNX и validation accuracy выводятся после обучения. Точный размер и точность зависят от версии библиотек и датасета. Каталог `commands.jsonl` используется сразу быстрым сопоставителем; новые фразы начинают работать без переобучения. Для улучшения RuBERT после накопления новых примеров отдельно запускай обучение.

## Установка и публикация ноутбучной версии

Рабочая ветка для ноутбука: `feature/lightweight-offline`. Она содержит полный набор действий основной версии и отдельный профиль `laptop`.

### На основном ПК

Собери автономный архив без обучения и без папки `assets/intent`:

```powershell
.\\build_portable.ps1 -Clean
```

Для сборки нужны Windows x64 и .NET 10 SDK. В ZIP включаются self-contained приложение, Vosk Small RU, Piper CLI и голос Denis, оба файла настроек, каталог команд, сценарий запуска и контрольная сумма. RuBERT/ONNX в ноутбучной сборке не используется. Рядом создаётся SHA-256 checksum.

Сборку можно выполнять на основном ПК: достаточно .NET 10 SDK и доступа к загрузке Vosk/Piper-ресурсов. На целевом ноутбуке не нужны обучение, Python, .NET SDK или GPU.

После подготовки архива и проверки SHA-256 его можно опубликовать в GitHub Releases:

```powershell
gh auth login
.\\Publish-LaptopRelease.ps1 -Tag laptop-v1.0.0
```

Скрипт проверит ветку, чистоту рабочего дерева и SHA-256, отправит ветку и прикрепит ZIP с контрольной суммой к релизу. Для следующей сборки используй новый тег, например `laptop-v1.0.1`.

### На ноутбуке

Скачай опубликованный архив через GitHub CLI:

```powershell
gh release download laptop-v1.0.0 --repo Huh-HAH-heh/STT-WORK-TTS --pattern "STT-WORK-TTS-Windows-x64.zip" --dir C:\\STT-Laptop
Expand-Archive C:\\STT-Laptop\\STT-WORK-TTS-Windows-x64.zip -DestinationPath C:\\STTWorkTTS
cd C:\\STTWorkTTS
.\\Start.cmd --profile laptop
```

На целевом ПК не нужны Python, .NET SDK, Ollama, llama-server или GPU. Приложение, Vosk и Piper уже находятся в архиве; первый запуск ноутбучного профиля не требует обучения, загрузки моделей или интернета.

### Прямая установка исходников

Если нужно получить исходники, клонируй ноутбучную ветку:

```powershell
git clone -b feature/lightweight-offline --single-branch https://github.com/Huh-HAH-heh/STT-WORK-TTS.git
```

Но для запуска без среды разработки используй готовый ZIP из Releases.

## Проверка

```cmd
Start.cmd --profile laptop --stt-demo
Start.cmd --profile laptop --intent-demo
```

`--stt-demo` проверяет микрофон, Vosk и маршрутизацию без синтеза. `--intent-demo` позволяет вводить команды текстом и проверять сопоставление без микрофона. Во время озвучки нажми `Esc`, чтобы немедленно остановить текущую фразу.

## Примеры команд

```text
открой блокнот
поставь таймер на 5 минут
установи громкость на 40 процентов
сделай погромче
покажи сведения о системе
покажи состояние батареи
покажи сетевые подключения
покажи адрес для телефона
покажи IP и порты Docker

Команда «покажи адрес для телефона» выводит LAN IPv4 компьютера, его сетевое имя и адреса веб-портов запущенных Docker-контейнеров. Она читает публикации из `docker ps` только по запросу, поэтому `ipconfig` вручную запускать не нужно. Телефон должен быть подключён к той же локальной сети. В Docker Compose публикуй порт, например `ports: ["8080:80"]`; веб-сервер внутри контейнера должен слушать `0.0.0.0`. Привязка хост-порта к `127.0.0.1` доступна только с самого ПК. При необходимости разреши этот порт во входящих правилах брандмауэра Windows для частной сети.
какое окно сейчас активно
поставь музыку на паузу
следующий трек
предыдущий трек
покажи активные процессы
закрой процесс номер три
закрой Discord
включи ночную гамму
верни обычную гамму
заблокируй компьютер
выполни в CMD tasklist /fo csv
```

Для закрытия процессов, блокировки ПК и буквальных CMD-команд требуется подтверждение. Закрытие процессов по имени ограничено безопасным списком; для точного завершения процесса требуется выбор из показанного списка и повторная проверка PID.

## Структура

```text
src/STT.WorkTTS/
  Audio/                 # запись и воспроизведение
  Configuration/         # профили и настройки
  Processing/            # каталог команд, парсер, опциональный RuBERT, валидация и Windows API
  Speech/                # Vosk и TTS adapters
tools/intent/
  dataset/commands.jsonl # обучающие примеры
  Train-RuBertIntent.py  # fine-tuning + ONNX INT8 export
  Train-RuBertIntent.ps1 # запуск обучения на основном ПК
  Install-RuBertIntentModel.ps1
assets/intent/            # создаётся обучением, не хранится в Git
```

Смотри `THIRD_PARTY_NOTICES.md` для сведений о сторонних моделях и лицензиях.
