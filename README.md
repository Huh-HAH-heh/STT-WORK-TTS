# STT Work TTS

Локальный голосовой помощник: **микрофон → STT → локальная обработка → TTS**.

Первая версия рассчитана на Windows и Python 3.12. Облачные API не используются: распознавание, обработка текста и синтез выполняются локально.

## Что уже работает в проекте

1. **Запись микрофона.** Аудио поступает в одноканальный `float32`-буфер в оперативной памяти. Промежуточный WAV не создаётся.
2. **STT.** faster-whisper распознаёт русскую речь непосредственно из массива аудиоданных. Включён VAD для отсечения длинных пауз.
3. **Очередь обработки.** Задание проходит через отдельный последовательный worker: распознавание → обработка текста → синтез. Очередь уже отделена от CLI, поэтому позже к ней можно подключить новые типы задач.
4. **Локальный ответ.** По умолчанию запрос отправляется в локальную Ollama с моделью Qwen3. Если Ollama не запущена, приложение не падает: оно передаёт исходный распознанный текст в TTS и показывает предупреждение.
5. **TTS.** Основной движок — Qwen3-TTS VoiceDesign. Он создаёт голос по текстовому описанию и поддерживает русский язык. По умолчанию выбран мягкий, тёплый женский голос; можно переключиться на мужской.
6. **Сохранение.** Исходная запись и синтезированный ответ сохраняются только при явном включении соответствующих флагов в `config.toml`.

## Установка (Windows)

Нужен Python **3.12 x64**. Из корня репозитория выполни:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\install.ps1
```

Скрипт создаст виртуальное окружение `.venv`, установит аудиозависимости, faster-whisper и Qwen3-TTS.

Альтернативная ручная установка:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -e .
python -m pip install qwen-tts
```

Если используется NVIDIA GPU, рекомендуется заранее поставить подходящую CUDA-сборку PyTorch по официальной инструкции PyTorch. Если CUDA не обнаружена, параметр `device = "auto"` выберет CPU; на CPU синтез большой моделью будет заметно медленнее.

## Локальная языковая модель

Установи Ollama отдельно, затем загрузи модель:

```powershell
ollama pull qwen3:4b
```

Ollama должна быть запущена локально на `http://127.0.0.1:11434`. Приложение вызывает её HTTP API только на твоём компьютере.

Чтобы временно отключить LLM и просто озвучивать распознанную фразу, измени в `config.toml`:

```toml
[assistant]
enabled = false
provider = "passthrough"
```

## Запуск

```powershell
.\.venv\Scripts\Activate.ps1
python -m stt_work_tts
```

Нажми Enter, скажи фразу и нажми Enter ещё раз. Приложение покажет распознанный текст, ответ локальной модели и воспроизведёт его голосом.

Первый запуск скачает веса моделей faster-whisper и Qwen3-TTS в локальный кэш. Последующие запуски используют кэшированные веса.

## Настройки голоса и памяти

Файл `config.toml` — основное место настройки.

**Переключение тембра:**

```toml
[tts]
voice_profile = "warm_female" # или "warm_male"
mode = "voice_design"
```

Женский профиль — мягкий, тёплый, бархатистый голос взрослой женщины, средняя высота, спокойная уверенная подача и лёгкая доброжелательность. Мужской — тёплый, насыщенный, спокойный тембр без искусственного баса. Оба профиля описаны отдельно в `src/stt_work_tts/tts/qwen.py`.

Поле `voice_description` позволяет полностью переопределить описание голоса. Оставь его пустым, чтобы использовать выбранный профиль.

**Запись исходного голоса на диск выключена по умолчанию:**

```toml
[audio]
save_recordings = false
recording_dir = "data/recordings"
```

Чтобы сохранять исходные записи в WAV, поменяй `save_recordings` на `true`.

Сохранение результата TTS независимо от исходной записи:

```toml
[tts]
save_speech = false
speech_dir = "data/speech"
```

На длительность записи установлен лимит `max_recording_seconds = 180`. Это ограничивает потребление оперативной памяти.

## Структура

```text
src/stt_work_tts/
  capture/       # запись микрофона в RAM
  stt/           # распознавание faster-whisper
  processing/    # LLM и очередь заданий
  tts/           # синтез Qwen3-TTS
  audio_output.py
  config.py
  domain.py
  main.py
config.toml
install.ps1
pyproject.toml
```

## Текущие ограничения первой версии

- Режим записи пока push-to-talk: начало и конец задаются Enter. Автоматическое определение конца фразы и непрерывный поток — следующий этап.
- LLM-обработка использует локальный Ollama. Без неё доступен прозрачный passthrough.
- Для голоса используется одна выбранная конфигурация тембра на запуск.
- Исполнение команд на компьютере, история диалога и прерывание речи пока не подключены.
- Модели загружаются лениво при первом обращении и остаются в памяти до завершения приложения.

Проект намеренно разделён на небольшие модули: аудиозахват, распознавание, текстовый процессор, очередь и синтез можно менять независимо.
