# STT Work TTS — C# edition

Локальный голосовой помощник для Windows x64. Основной конвейер: **микрофон → Vosk STT → быстрый парсер / RuBERT-tiny2 ONNX → C# Intent Router → Windows API → TTS**.

## Архитектура

- **STT:** Vosk Small RU, полностью локально.
- **Сопоставление команд:** сначала дешёвый каталог фраз и синонимов. Уверенное совпадение сразу переводится в IntentPlan без запуска нейросети; остальные запросы классифицирует RuBERT-tiny2 ONNX INT8 на CPU.
- **Извлечение параметров:** детерминированный C# код. Модель выбирает намерение, а C# извлекает число, приложение, URL или процесс и формирует типизированный IntentPlan.
- **Проверка:** IntentPlanValidator проверяет допустимые действия, аргументы и соответствие команде пользователя.
- **Исполнение:** каталог типизированных действий Windows API / Win32 / Core Audio и отдельный безопасный CMD-адаптер.
- **TTS:** Silero v5.6 по умолчанию; xVibe как дополнительный движок; Piper и SAPI доступны как лёгкие варианты.
- **Qwen3-4B:** необязательный генератор свободных ответов/текстов. Он не используется для сопоставления команд и отключён по умолчанию; включается отдельно только при необходимости.

Модель не генерирует PowerShell, CMD или произвольный код. Опасные действия (блокировка ПК, закрытие процесса, буквальный CMD-запрос) требуют подтверждения. Закрытие процесса начинается со штатного CloseMainWindow; принудительное завершение не выполняется автоматически. CMD разрешает только отдельные диагностические команды из whitelist.

## Профили запуска

### Основной компьютер

После обучения модели запускай:

```cmd
Start.cmd
```

Этот профиль использует каталог быстрых совпадений + RuBERT-tiny2 для команд и Silero для речи. Qwen3-4B по умолчанию отключена. Для свободных ответов её можно отдельно включить через `Generation.Enabled` в `src/STT.WorkTTS/appsettings.json`.

### Слабый ноутбук (4 ГБ RAM)

```cmd
Start.cmd --profile laptop
```

Профиль ноутбука:
- Vosk Small RU для распознавания;
- RuBERT-tiny2 ONNX INT8 для понимания команд;
- Piper для синтеза речи;
- Qwen3-4B выключена;
- llama-server не запускается;
- ONNX Runtime работает на CPU с ограничением до двух потоков.

Это не удалённый клиент: распознавание речи, классификация намерения, заполнение параметров, проверка и Windows API выполняются на самом ноутбуке.

## Подготовка модели (один раз на основном ПК)

RuBERT-tiny2 — предобученный русскоязычный энкодер, а не готовый классификатор наших действий. Сначала его нужно дообучить на примерах из `tools/intent/dataset/commands.jsonl`. Не запускай обучение на ноутбуке с 4 ГБ RAM.

1. Установи Python 3.12 x64 на основном компьютере.
2. Из корня репозитория выполни:

```powershell
.\tools\intent\Train-RuBertIntent.ps1
```

3. Скрипт создаст изолированное окружение, скачает базовую RuBERT-tiny2, обучит классификационную голову, экспортирует ONNX и динамически квантует MatMul/Gemm в INT8.
4. Готовые файлы появятся в `assets/intent`:
   - `rubert-tiny2-intent-int8.onnx`
   - `vocab.txt`
   - `labels.json`
   - `training-info.json`

Размер ONNX и validation accuracy выводятся после обучения. Точный размер и точность зависят от версии библиотек и датасета. Каталог `commands.jsonl` используется сразу быстрым сопоставителем; новые фразы начинают работать без переобучения. Для улучшения RuBERT после накопления новых примеров отдельно запускай обучение.

## Установка на ноутбук

На основном ПК после обучения собери portable-архив:

```powershell
.\build_portable.ps1
```

Сборка проверит наличие RuBERT-файлов, включит модель в архив вместе с Vosk и Piper. Перенеси `STT-WORK-TTS-Windows-x64.zip` на ноутбук, распакуй и запусти:

```cmd
Start.cmd --profile laptop
```

Либо клонируй ветку и перенеси папку `assets/intent` с обученной модели:

```powershell
git clone -b feature/rubert-tiny2-router --single-branch https://github.com/Huh-HAH-heh/STT-WORK-TTS.git
cd STT-WORK-TTS
# Скопируй обученную папку assets\intent с основного ПК
Start.cmd --profile laptop
```

Первый запуск автоматически скачает компактную модель Vosk, если она отсутствует. Для профиля laptop не требуется Python, Ollama или llama-server; TTS использует Piper. Интернет нужен для первичной подготовки Vosk/зависимостей или переноса файлов.

## Проверка

```cmd
Start.cmd --profile laptop --stt-demo
Start.cmd --profile laptop --intent-demo
```

`--stt-demo` проверяет микрофон, Vosk и маршрутизацию без синтеза. `--intent-demo` позволяет вводить команды текстом и проверять сопоставление без микрофона. Во время озвучки нажми `Esc`, чтобы немедленно остановить текущую фразу.

## Структура

```text
src/STT.WorkTTS/
  Audio/                 # запись и воспроизведение
  Configuration/         # профили и настройки
  Processing/            # парсер, RuBERT, валидация, Windows API
  Speech/                # Vosk и TTS adapters
tools/intent/
  dataset/commands.jsonl # обучающие примеры
  Train-RuBertIntent.py  # fine-tuning + ONNX INT8 export
  Train-RuBertIntent.ps1 # запуск обучения на основном ПК
  Install-RuBertIntentModel.ps1
assets/intent/            # создаётся обучением, не хранится в Git
```

Смотри `THIRD_PARTY_NOTICES.md` для сведений о сторонних моделях и лицензиях.
