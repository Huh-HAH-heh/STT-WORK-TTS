# STT Work TTS

Компактный автономный голосовой помощник для Windows x64 и слабых CPU-ПК.

Конвейер:

    Микрофон → Vosk Small RU → локальные команды → Piper TTS → динамики

Никаких облачных API, Ollama, GPU или большой языковой модели. Аудио и распознанная речь остаются на компьютере.

## Почему стек лёгкий

- Vosk Small RU — компактное офлайн-распознавание русской речи на CPU. Архив исходной модели около 45 МБ.
- Piper TTS — нейросетевой синтез через ONNX Runtime, без PyTorch. В архиве один русский голос medium около 63 МБ.
- PCM16 — аудио сразу хранится в компактном байтовом буфере, без NumPy-массивов в собственном аудиотракте.
- Один worker — распознавание, обработка и синтез идут последовательно.
- Piper по умолчанию работает с одним CPU-потоком.
- Загружается только выбранная модель голоса.
- Нет постоянного потребителя RAM в виде LLM.

## Полностью автономный запуск

Для конечного пользователя предусмотрен переносимый ZIP.

1. Открой вкладку Actions репозитория.
2. Скачай artifact STT-WORK-TTS-Windows-x64 из последнего успешного запуска workflow Build offline Windows archive.
3. Распакуй ZIP.
4. Запусти Start.cmd.

На целевом ПК не нужны Python, pip, интернет, Ollama, GPU или предварительная установка моделей. Исполняемый файл и модели уже находятся в архиве. При запуске ничего не скачивается.

### Получение готового ZIP через GitHub Actions

Workflow собирает приложение после push в feature/lightweight-offline и по ручному запуску из Actions. Артефакт хранится ограниченное время в соответствии с retention-days в workflow.

### Самостоятельная сборка

Сборка выполняется один раз на компьютере разработчика. Нужны Windows x64, Python 3.12 x64 и интернет только на этапе сборки.

    git clone -b feature/lightweight-offline --single-branch https://github.com/Huh-HAH-heh/STT-WORK-TTS.git
    cd STT-WORK-TTS
    .\RUN.cmd

RUN.cmd автоматически запускает build_portable.ps1, если готовой сборки ещё нет.

Результат:

    STT-WORK-TTS-Windows-x64.zip

Сборщик загружает Vosk Small RU и один Piper-голос, устанавливает зависимости, собирает EXE через PyInstaller и упаковывает его вместе с моделями. Получившийся ZIP переносится на другой Windows x64 ПК и запускается без сети.

Для прямой сборки:

    powershell -ExecutionPolicy Bypass -File .\build_portable.ps1

Для чистой пересборки:

    powershell -ExecutionPolicy Bypass -File .\build_portable.ps1 -Clean

## Голос

По умолчанию:

    [tts]
    voice = "male"
    cpu_threads = 1

Встроенный голос — русский Piper Denis. Выбор одного голоса уменьшает размер ZIP и количество одновременно хранимых ресурсов.

Код поддерживает второй путь для женской Piper ONNX-модели через настройку female_model. Но официальная карточка популярной ru_RU-irina-medium указывает лицензию датасета Unknown. Поэтому Irina не включается в публичную автономную сборку. Добавляй женскую модель вручную только после проверки прав на её распространение.

Piper не генерирует новый тембр из текстового промпта: используется готовая модель диктора. Это компромисс ради автономности, низкой нагрузки и скорости CPU-инференса.

Piper runtime имеет лицензию GPL-3.0-or-later. Перед публичным распространением приложения проверь совместимость лицензии проекта и выполни требования Piper. Подробности — в THIRD_PARTY_NOTICES.md.

## Что умеет обработчик без LLM

Скажи «помощь», чтобы услышать список команд.

- «Который час?» — текущее системное время.
- «Какая сегодня дата?» — системная дата.
- «Посчитай 17 плюс 25» — простая арифметика.
- «Запомни купить молоко» — заметка в RAM.
- «Покажи заметки» — заметки текущего запуска.
- «Очисти заметки» — очистка списка.

Это не свободный диалог с ИИ. Неизвестная команда будет распознана и озвучена, а не выдуманно исполнена. Обработчик отделён от STT и TTS, поэтому новые действия можно добавлять независимо.

## Настройки RAM и файлов

Все флаги сохранения выключены по умолчанию:

    [audio]
    save_recordings = false

    [work]
    save_notes = false

    [tts]
    save_speech = false

Исходное аудио, заметки и синтезированная речь остаются в памяти и исчезают после завершения программы. Нужное сохранение можно включить отдельно в config.toml.

Одна запись ограничена 90 секундами. Максимальный аудиобуфер при 16 кГц mono PCM16 — около 2,9 МБ.

## Структура

    src/stt_work_tts/
      capture/        # микрофон и PCM16 RAM
      stt/            # Vosk
      processing/     # очередь и офлайн-команды
      tts/            # Piper
      audio_output.py # воспроизведение и WAV
      config.py
      domain.py
      main.py

    assets/
      models/         # скачивается при сборке ZIP
      voices/         # скачивается при сборке ZIP

    build_portable.ps1
    run_app.py
    Start.cmd
    RUN.cmd
    config.toml

## Ограничения

- Запись пока push-to-talk: Enter начинает, Enter завершает.
- Vosk Small уступает большим моделям по точности при шуме, нескольких говорящих и сложной речи.
- Обработчик команд детерминированный: свободный диалог требует более мощной локальной модели и не входит в минимальную сборку.
- Piper использует готовый тембр диктора, а не произвольное voice design или клонирование голоса.
- Архив собирается под Windows x64.
- Скорость и RAM зависят от конкретного CPU, памяти и аудиодрайвера. Проверки на целевых слабых ПК ещё не проводились.
