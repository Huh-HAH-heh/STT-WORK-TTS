# STT Work TTS

Локальный голосовой помощник на Python: микрофон → распознавание речи → локальная обработка → синтез ответа.

Первая версия строится вокруг четырёх принципов:

- Запись с микрофона хранится в оперативной памяти; сохранение WAV на диск отключено по умолчанию и включается в `config.toml`.
- STT работает локально через faster-whisper.
- Текст передаётся через очередь обработки; для содержательного ответа предусмотрен локальный Ollama, без облачных API.
- TTS вынесен в отдельный адаптер. Основной движок — Qwen3-TTS VoiceDesign с описываемым голосом на русском языке.

Подробная установка и запуск будут описаны ниже по мере сборки первой рабочей версии.
